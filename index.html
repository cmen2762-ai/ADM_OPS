Instal Aplikasi ADMOPS

Pasang ikon sekolah langsung di layar utama

Aplikasi ADMOPS siap diinstal dengan ikon Logo SDN 22 Tanah Keras. Jika pop-up instal otomatis tidak muncul di browser Anda, ikuti langkah singkat berikut:
Microsoft Edge (Laptop / PC):

Klik ikon App available (Instal ADMOPS) di sisi kanan kolom alamat URL, atau klik menu (•••) → Aplikasi (Apps) → Instal situs ini sebagai aplikasi.

Google Chrome (Laptop / Android):

Klik ikon Instal di ujung kanan address bar, atau buka menu titik tiga (⋮) → Simpan dan bagikan / Tambahkan ke layar utama → Instal aplikasi.

iPhone / iPad (Safari):

Ketuk tombol Bagikan (Share) di bagian bawah layar, lalu pilih Tambah ke Layar Utama (Add to Home Screen).
